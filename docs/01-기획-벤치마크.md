# 데이트 코스 앱 — 기획 v0.1

## 1. 개발 범위와 순서
1. **지역 + 시간대 선택** (MVP)
2. **AI 동선 추천** (MVP) — 시간대별 코스 + 이동 동선
3. 캘린더 일정 추가 — 마지막 단계
- 장소 데이터: 초기에는 목업 데이터 → 이후 **네이버 지도 API**(지역 검색 / Directions)로 교체

## 3. "여자친구가 이미 가고 싶은 곳을 정해둔 경우" — 아이디어

### A. 고정 핀(Must-go) — 기본 기능 ★MVP
- 코스 생성 전 **"꼭 갈 곳 추가"** 단계 (건너뛰기 가능)
- 장소마다 **시간 고정 여부** 선택
  - 🔒 시간 고정: "19:00 예약해둔 파스타집" → 그 시각에 맞춰 앞뒤를 채움
  - 📌 순서 자유: "그 소품샵은 꼭" → AI가 동선상 가장 자연스러운 위치에 배치
- AI는 고정 핀을 **뼈대**로 두고 빈 시간만 채움 (식사→카페→액티비티→술 흐름 유지)
- 고정 핀이 지역 밖이면 → "지역을 OO까지 넓힐까요?" 제안

### B. 링크로 여자친구에게 물어보기 ★MVP 다음
- 앱 설치 없이 **웹 링크** 하나로 공유 (카카오톡 공유)
- 여자친구가 링크에서 ① 가고 싶은 곳 직접 추가 ② 후보 장소 스와이프
- 둘 다 좋아요한 곳 = **매치** → 자동으로 고정 핀이 됨
- 서프라이즈 모드: 여자친구에게는 결과 코스를 숨기고 "취향만" 받기

### C. 붙여넣기로 장소 추가
- 인스타/네이버 지도 링크를 붙여넣으면 장소 자동 인식 → 고정 핀
- (여자친구가 카톡으로 보낸 "여기 가자" 링크를 그대로 활용)

### D. 동선 충돌 처리
- 고정 핀끼리 이동시간이 부족하면 경고 + 대안 제시
  ("성수 19:00 → 연남 20:00는 이동 40분이라 빠듯해요. 연남을 21:00로 미룰까요?")

## 4. MVP 화면 흐름
1. 홈 (넷플릭스형): 히어로 추천 코스 + 테마별 가로 줄
2. 코스 만들기 ①: 지역 선택 (성수/홍대·연남/강남/잠실/을지로·종로 …)
3. 코스 만들기 ②: 날짜·시간대 (점심 / 오후 / 저녁 / 밤, 시작–끝 시각 슬라이더)
4. 코스 만들기 ③: 꼭 갈 곳 (고정 핀) + 취향 칩 (선택)
5. 결과: 시간표형 타임라인 + 지도 동선 + 구간 이동시간, 장소 교체(스와이프)
